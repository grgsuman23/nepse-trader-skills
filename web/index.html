    How accurate has each setup been?

    "Edge" is the setup's average minus the average for random entries on the same stocks with the same exits. Random entries lose roughly the round-trip cost, so a setup has to clear that before it can make money. An edge is real only if it holds in both periods and is larger than about 2 standard errors (SE).

    Known limits

    • Survivorship bias: the data covers only companies listed today, so delisted and merged names are missing.
    • Prices are adjusted for bonus and rights issues using NEPSE's base-price reset.
    • No slippage is modelled beyond filling gaps at the open.
    • Fees and CGT are as of 21 Nov 2026 and changed twice in 2026.
